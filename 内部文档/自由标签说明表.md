## 0. 为什么要单独立这张表（体检实证）

| 现象 | 数据 | 后果 |
|---|---|---|
| 单例标签过多 | 实库 566 个唯一标签，**469 个（83%）只出现一次** | 查询词与条目标签对不上，召不回 |
| 等价表覆盖太窄 | `tag-equivalence.json` 只收 17 组技术同义词（发版/上线/deploy…），与实库高频词（原话/推断/坑/dsh…）几乎不重叠 | 同义归一帮不上忙 |
| 噪声标签 | 纯数字（`3190`/`14080`/`0`/`2`）、来源标记（`原话`14 / `推断`16） | 不会被当查询词，却白占 `e_ratio` 分母，放大 §4.1 假查空 |
| 空标签 | 可见集合里 9 条条目自由标签为空（合并带入，绕过写入侧 `TAGS_EMPTY`） | 除「浏览形态」外任何带标签查询都召不回 |

**与 §4.1 的关系**：阈值 0.5→0.3 修的是「分母大导致召不回」的闸门；
本表修的是「分母里塞了不该塞的词」的写入规范。两者协同，但**不能互相替代**。

## 1. 写入侧：标签怎么打

### 1.1 从哪三个方向取（schema.json `writeRoutes` 既有口径）

| 方向 | 回答什么 | 例子 |
|---|---|---|
| **作用** | 它帮解决什么 | `发版检查` `权限隔离` `超时重试` |
| **注意事项** | 容易踩的坑 / 约束 | `别用UTC` `需先build` `windows路径` |
| **内容关键词** | 正文里会出现的实词 | `csv` `token` `迁移` |

### 1.2 该打

- 用**正文里可能出现的实词**、短词、一个标签一个概念。
- 三方向各取 1~2 个，覆盖「将来会怎么查它」。
- 同义变体交给程序等价表归一（只打你这边那个词）。
- 每类带一个**类名标签**（`规矩`/`决策`/`交代`/`踩坑`/`纠正`/`流程`），方便按类聚。

### 1.3 不该打

| 别打 | 为什么 |
|---|---|
| 纯数字（`3190`/`0`/`2`） | 不会被当查询词，白占分母 |
| 来源标记（`原话`/`推断`） | 同上；来源信息应写进正文或 `basis`，不进标签 |
| 转述句（「我要查一下关于…」） | 不是实词，查询时不会这么给 |
| 同义变体（`发版` 与 `上线` 都打） | 归一后重复，分母虚高 |
| 超过 6~8 个还不收 | 标签越多分母越大，少词查询越难过闸门；能拆条就拆条 |
| `|` | 库文件用它分隔标签，含 `|` 会被 `TAG_CONTAINS_PIPE` **拒写** |

### 1.4 硬边界

- 数量 **1~20 个**（`schema.json limits.tagsMax`）；空数组拒写（`TAGS_EMPTY`）。
- **建议区间 3~6 个**：实库平均 4.71，出厂种子示范用 3 个。
- 一个标签一个概念，短词优于长句。

## 2. 读取侧：标签怎么给

- **一次给 1~3 个词最常见**，优先「内容关键词」或「作用」类短实词。
  （§3 探针：出厂 0.5 下 k=1 假查空率 98.5%；标定到 0.3 后 k=2→7.6%、k=3→0%。）
- `形态` 必填，与标签配合；想浏览某形态全部 → `自由标签` 留空。
- 直接给**数组**，不要给自然语言让程序猜。
- **查空了怎么办**：按无返回正常继续，**不要反复换说法重试**。
  要再找就：留空只按形态浏览、换形态、或调整标签。
- 真假查空的严格定义见《整理程序说明》§1：跨项目/跨身份查空是正常隔离，不是缺陷。

## 3. 交付方式（关键：不撑破注入预算）

| 通道 | 状态 |
|---|---|
| 机器可读源 `free-tag-rules.json` | ✅ 新增，`templates/` 下 |
| 人读副本（本文件 / `标签字典.md`） | ✅ 新增/更新 |
| `dtm_write` 的 `自由标签` 参数 description | ✅ 要点前置（`【自由标签规则】…`） |
| `dtm_recall` 的 `自由标签` 参数 description | ✅ 读取侧要点前置 |
| 每轮注入的 **section** | ❌ **禁止**。实测 5998/6000 字节只剩 2 字节；且 section 一变毁整段 KV cache 前缀 |
| 新增第 11 个工具 | ❌ **禁止**。工具数恒为 10（K1 裁定） |

`preset/tool-defs.js` 的 `renderTagRules(side)` 同步读表（mtime 缓存），读不到用内置兜底，
**绝不抛错**——`buildToolDefs()` 契约要求「无 schema 时也能工作」。

## 4. 验收

- 注入总字节仍 ≤6000（L4 实测 5998）、工具数仍 10（K1）。
- 新写入条目标签数收敛到 3~6，单例标签占比下降、纯数字/来源标记消失。
- 按 `scripts/probe-recall.mjs` 探针，同口径假查空率随标签规范化进一步下降。
- 改表文案只需改 `free-tag-rules.json`（改完即生效，mtime 热更新），
  无需重启宿主、无需改注入。
