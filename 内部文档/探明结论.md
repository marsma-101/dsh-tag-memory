## 1. 工具注册 `ctx.tools.register(defineTool({...}))`

**来源**：`@deepseek-ai/dsh-tools/README.md`

```ts
import { defineTool } from '@deepseek-ai/dsh-tools'

ctx.tools.register(defineTool({
  name: 'read_file',
  description: 'Read a file from disk.',
  parameters: {
    path: { type: 'string', required: true, description: 'Absolute file path' },
    offset: { type: 'number' },
    limit: { type: 'number' },
  },
  output: {
    schema: { type: 'string' },
    render: (_args, value) => [{ type: 'text', text: value }],
  },
  async execute(args, exec) {
    // args 已按 parameters 定型；exec.signal 用于取消
    return readFile(args.path, { encoding: 'utf8', signal: exec.signal })
  },
}))
```

**要点**
- `parameters` 是统一 schema DSL：`string` / `number` / `integer` / `boolean` / `null` / `array` / `object` / `json` / `oneOf`
- 每个参数是对象，`required: true` 标必填，`description` 给模型看
- `output.schema` 声明返回类型；`output.render` 决定模型看到什么
- `execute(args, exec)` 返回**只含声明过的 JSON 值**；`exec.signal` 用于超时/取消
- **参数在校验后才执行**，非法输入变成普通错误结果（不中断轮次）
- 注册即模型可见——registry 自动把 schema 喂给 system-prompt assembly

**对本插件的意义**：`dtm_retag` 的 `basis` 必填可以直接用 `required: true` 表达；标签含 `|` 的拒写放在 `execute` 里抛错。

## 2. 系统提示注入 `ctx.systemPrompt.section(...)`

**来源**：`@deepseek-ai/dsh-system-prompt/README.md`

```text
ctx.systemPrompt.section({
  name: 'tool:bash',
  order: 100,
  text: 'Prefer bash for file and process operations.',
})
```

**要点**
- `name` 唯一标识、`order` 排序、`text` 是注入内容
- `interpolate: false` 可保留 `{{...}}` 字面（我们注入的字典里有花括号时必须设，否则会被当变量解析失败）
- 变量：`ctx.systemPrompt.variable('name', () => 'value')`，文本里用 `{{name}}` 引用
- **agent 作用域优先**：通过 `agent.ctx` 注册只影响该 agent
- 同一个 name 重复注册会被覆盖（不是并列）

**对本插件的意义**：`标签字典.md` + 身份状态用一次 `section()` 注入；
**内容里有 `{{` 时必须 `interpolate: false`**，否则 assembly 会因未解析变量而失败。

## 3. 会话身份：`ctx.sessionProjections`

**来源**：`@deepseek-ai/dsh-session-projection/README.md`

```text
const definition = {
  key: 'identity',
  stateSchema: identityStateSchema,
  stateVersion: 1,
  init: (_header, _inheritedEventCount) => ({ agentName: null }),
  apply: (state, event) => event.type === 'tm/identity-bound'
    ? { agentName: event.data.agentName }
    : state,
  wire: {
    viewSchema: identityViewSchema,
    view: state => ({ agentName: state.agentName }),
  },
}
```

**要点**
- `key` 状态键；`stateVersion` 字段或语义变就 +1
- `init(header, inheritedEventCount)` 初始化；**不能从 `firstLiveSeq` 推断 fork 切点**
- `apply(state, event)` **必须同步**，且对不关心的事件**返回同一引用**（引用不变=零下游开销）
- `wire.view` 把状态投影给客户端；**必须复用引用**才不触发发布
- `register(definition)` 注册，返回 disposer，可 yield 进 `ctx.effect()`
- **host-only 单元（无 `wire`）不暴露给客户端**

**对本插件的意义**：
- 会话身份绑定用它，**resume/fork 能正确恢复**（内存 map 会丢）
- 身份状态要显示在 UI → 加 `wire` 块；只给工具用就不加

## 4. 客户端 ↔ 宿主：`ctx.commands.register()`（不是自建 HTTP）

**来源**：`@deepseek-ai/dsh-commands/README.md` + `references/user-actions.md`

```text
ctx.commands.register({
  name: 'plan',
  description: 'Enter plan mode',
  input: { hint: '<message>' },
  handler: ({ agent, rawInput }) => {
    // 直接对 agent 运行，不产生模型消息
    return { kind: 'success', text: 'plan mode selected' }
  },
})
```

**要点**
- 命令**不产生模型消息**，结果在 UI 渲染
- `handler` 返回 `{ kind: 'success' | 'error', text }`
- `recordInput` 默认 true（记进 session log）；若领域事件已带载荷可设 false 避免重复
- **同一作用域重复注册同名会抛错**
- 命令目标可以是某个 agent，也可全局

**对本插件的意义**：这就是"UI 调宿主方法"的官方入口。
**一个操作两个调用者**的实现：
- UI 点"保存" → 走 command handler → 调宿主方法
- 模型调 `dtm_retag` → 也调同一个宿主方法
- **两边结果必然一致**

> ⚠️ 待确认：command handler 是否适合传复杂对象（如整个条目）。
> 若不适合，改用 `ctx.remote`（`@deepseek-ai/dsh-api-remotes`）或把参数序列化成 JSON 字符串。
> 这点在实现 client.api.js 前需再验一次。

## 5. UI 槽位与客户端模块

**来源**：`cordis-plugin-development/references/ui-plugin.md` + `templates/decoration/`

**客户端模块形态**（官方模板原文）：

```js
window.__ModuleLoader__.load({
  id: '<package-name>',
  factory(require) {
    const React = require('react')
    const h = React.createElement
    function MyComponent() { /* ... */ }
    return {
      inject: ['slots'],
      apply(ctx) {
        ctx.slots.inject('conversation.composer.dock', () => ctx.slots.register({
          name: 'conversation.composer.dock', id: 'my-decoration', order: 5,
        }, MyComponent))
      },
    }
  },
})
```

**要点**
- `id` 必须等于**包名**
- React 从 `require('react')` 取（浏览器模块表），**不用自己装**
- `inject: ['slots']` 声明依赖
- `ctx.slots.inject(ownerKey, () => ctx.slots.register(slotName, component))`
- **注册在回调里**：owner 塌陷时自动销毁、回来时重装

**待确认**：本插件该挂哪个 slot（管理页面）。需用 `Slots.listSubTree` 在运行时查，
候选可能是 `settings.*` 或 `sidebar.*` 系列。
**实现前必须查实**，不能猜。

## 6. 插件包清单与安装

**来源**：`references/host-plugin.md` + `templates/decoration/package.json`

```json
{
  "name": "@local/my-decoration",
  "version": "1.0.0",
  "private": true,
  "type": "module",
  "exports": {
    ".": "./index.js",
    "./client": "./client.js",
    "./locale/*.json": "./locale/*.json",
    "./icon": "./icon.svg"
  },
  "files": ["index.js", "client.js", "cordis.patch.yml", "locale/*.json", "icon.svg"],
  "dsh": {
    "bundle": { "patch": "./cordis.patch.yml" },
    "client": {
      "platform": "web",
      "immediately": true,
      "inject": ["@deepseek-ai/dsh-client-ui-conversation"]
    }
  }
}
```

`cordis.patch.yml`：
```yaml
- insert:
    - id: my-decoration
      name: '@local/my-decoration'
```

**要点**
- `dsh.bundle.patch` 指向补丁；`dsh.client` 声明客户端
- `exports` 必须含 `./client`、`./locale/*.json`、`./icon`
- `files` 白名单**必须覆盖全部运行时文件**（新增模块要更新）
- 本地目录安装是**链接**，`files` 不过滤链接目录 → **更要保证 `内部文档/` 不在发布路径**
- `locale/en.json` 里 `{ "meta": { "title": "...", "description": "..." } }`
- icon ≤ 256KiB，SVG/PNG/JPEG/WebP，必须在包内
- **安装只用 `install_bundle`**；返回的 `application` 和 `warnings` 决定是否真生效

## 7. 给各开发者的结论摘要

| 角色 | 必须照这个写 |
|---|---|
| **preset-dev** | `ctx.tools.register(defineTool({...}))`；`ctx.systemPrompt.section({name,order,text})`，含 `{{` 时设 `interpolate:false` |
| **host-dev** | 身份用 `ctx.sessionProjections`（`apply` 同步、返回同引用）；UI 入口用 `ctx.commands.register()` |
| **client-dev** | `window.__ModuleLoader__.load({id:包名, factory(require){...}})`；React 用 `require('react')`；`ctx.slots.inject` + `register` |
| **Lead** | `package.json` + `cordis.patch.yml` 按上面第 6 节；只用 `install_bundle` |
