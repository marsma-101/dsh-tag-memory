# 标签章程

> **本文件是 `tags.md` 的简明版**——只列「有哪些标签」。完整的含义与调用时机见 `tags.md`。
> **两者要同步改。**

---

## 一、四个维度（核心）

| 维度 | 回答的问题 | 取值 | 升降靠什么 |
|---|---|---|---|
| `类型` | **这是什么？**（主开关）| 原文 / 记忆 / 固定 | 写时定，不升降 |
| `深度` | **能不能当规律用？** | 情景 / 语义 / 程序 | **认识**在动 |
| `稳定性` | **该不该核对？** | 稳定 / 观察 / 易变 | **环境**在动 |
| `距离` | **要不要进上下文？** | 常驻 / 按需 / 深藏 | **使用**在动 |

**激活规则**：`深度` **仅当 `类型=记忆`** 时填；`类型=原文 / 固定` 时留白。

**合并原则**：分类规则或升降级规则**相同或相近的合并**——
否则筛出来总是一样，多写一套解释就白写了。

**来历**：`类型` 是 2026-10-13 新增的主开关（原文 / 记忆 / 固定）；
用户「三层」+ 旧「时效」→ `稳定性`；CoALA「四层」→ `深度`（形态三值）+ `距离`（工作记忆那一层）；
mnemon「三层到达」+ auto-memory「详细度」→ `距离`。
**没单独成维度的**：meow 的「关于谁」并入 `角色`/`项目`；mneme 的「还有效吗」并入 `状态`。
（`深度` + `距离` 合起来 = 完整四层，见 `architecture.md` §六。）

## 二、辅助标签

| 列 | 取值 | 必填 | 说明 |
|---|---|---|---|
| `角色` | 智能体名（多设备时 `名@机器`）/ 临时智能体 | 建议 | **谁写入的**（工作环境标识） |
| `依据` | 原话 / 推断 / 外部 | ✓ | **这话是谁说的** |
| `项目` | 通用 / 项目名 | 建议 | 哪儿的事 |
| `状态` | 生效 / 被取代 / 已归档 | ✓ | 还有效吗 |
| `关键词` | 自由填，逗号分隔 | | 兜底检索 |
| `工具` | python / git / dsh / nowen-note … | | 涉及的工具 |
| `版本` | v1 / v2 … | | **冲突时区分两条都对的记忆**（当前全空是对的，见 `tags.md`） |
| **自定义** | 按需 | | 加了要登记 |

**⚠️ `角色` 与 `依据` 别混**：

| 列 | 回答 | 例 |
|---|---|---|
| `角色` | **谁写入的**（哪台机器、哪个智能体） | `萧潇@工作机` |
| `依据` | **这话是谁说的** | `原话`（主子亲口）/ `推断`（萧潇归纳）/ `外部`（抄来的） |

## 三、判据（一句话）

| 判什么 | 判据 |
|---|---|
| 类型 | **原文 / 提炼结论 / 本机硬信息？** 原话原文→`原文`；提炼的结论→`记忆`；本机硬信息（python 装哪）→`固定` |
| 深度 | **事件→`情景`；规律→`语义`；做法→`程序`**（仅 `类型=记忆`）|
| 稳定性 | **没意外会不会变？** 不会→`稳定`；拿不准→`观察`；会变→`易变` |
| 距离 | **召回优先级：多久用一次？** 每轮→`常驻`；项目里常用→`按需`；基本不用→`深藏` |
| 项目 | **换个项目还成立吗？** 成立→`通用`；不成立→项目名 |

**⚠️ `深度` 只在 `类型=记忆` 时打。**

## 四、打标签的度

> **打够将来真能检索到它就行，多打是噪音。**

| 情形 | 打什么 |
|---|---|
| 文件位置、物理规律 | `类型=固定` `距离=按需` —— **够了** |
| 某项目的做法 | `类型=记忆` `深度=程序` `稳定性=稳定` `项目=X` `角色=X` `距离=按需` |
| 通用判断原则 | `类型=记忆` `深度=语义` `稳定性=稳定` `项目=通用` `距离=常驻` |

**不填的列留空。**

## 五、加/改标签的规矩

规则：**标签可以随时加、随时改**，但：

1. **加列**：CSV 表头**末尾追加**（不要插中间——会错列），已有行留空
2. **同步登记进 `tags.md`**，写清三件事：**含义 / 什么时候打 / 什么时候调用**
3. **改列名**：同步改所有引用它的文档
4. 加完**告知用户**一句

**为什么必须登记**：**没登记的标签 = 以后想不起来用它**。

### ⭐ 标签从哪来：按「存」和「读」的问题调整（总纲）

> **根据「存」和「读」的问题，调整标签的添加规则、修改标签字典。**（主子 2026-10-12 定）

| 哪一环出问题 | 该怎么动标签 |
|---|---|
| **存**：存不进 / 存进去说不清 | 加列，或改取值 |
| **读**：筛不出 / 筛错 | 补取值、改「什么时候打」 |
| **整理**：判不了留还是降 | 加状态值，或明确判据 |

**⚠️ 不要「为了完整」加标签**——加标签的唯一理由是「现有标签解决不了某个具体的存/读问题」。
说不清具体问题的，**不加**。完整版见 `tags.md` 第十节。

## 六、书写纪律

- 值里**不要有逗号**（会破坏 CSV 列）；要写逗号就整格包引号
- 值里**不要有换行**
- 筛标签时**用等号全匹配**（`稳定性=稳定`），不要用「包含」——`稳定` 会误命中 `稳定X`
