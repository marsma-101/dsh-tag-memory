## 〇、运行方式与总纪律

### 运行方式
- 闸门①：`node --test tests/`，纯 `node:test` + `node:assert`，**零 Cordis / 零 DSH**。
- 闸门②：最小假 `ctx` stub 加载 `preset/tools.js` / `index.js`（官方许可的"工具注册冒烟"）。
- 闸门③：清单解析 + `node --check` + grep 禁止项 + 视觉如实报告。
- 临时数据目录一律 `mkdtemp`（唯一自有目录），`after()` 必清理，**绝不碰插件真实 `data/`**。
- 时钟：一律走**可注入 `now`**（Q8 裁定），**不靠子进程 TZ + 真实时间**。

### 纪律（违反即失职）
1. 只报问题，**不修业务代码**；发现的问题写进报告交回对应 owner。
2. **不许为了通过而放宽或删除断言**。认为断言写错 → 只报告 + 给建议，**由 Lead 定**。
3. 验证**不造假**：不另起浏览器、不改 HOME、不翻浏览器配置、不找 token、
   不找光栅化工具 / Quick Look / 把 SVG 导出预览图、**不模拟 React/DOM**、mock 截图不算验证。
   无浏览器控制 → **如实报"视觉未验证"**。
4. 旁见不动手。
5. 报告四段式：`结论` + `证据（原始输出）` + `失败项（期望 vs 实际）` + `没验到的部分`。

1. **形态为空的条目，浏览任何具体形态都返回不到** —— 它本来就不是那个形态。修复途径是整理补形态。

3. **跨形态放行口**（形态不命中 + `q_ratio=1` + `时距=32` → 50 分 → 返回）—— 文档明写"有意保留"。
