修 dtm_retag 的"省略=不改"语义（前端真实对话验证通过）

## 事故经过

模型调 dtm_retag 只想改「稳定性」，被连续拒绝 3 次：
  FIELD_EMPTY: 形态 不能改成空值
  FIELD_EMPTY: 项目 不能改成空值
  TAGS_EMPTY : 自由标签不能为空

## 根因

preset/tools.js 的 executeRetag 无条件把 5 个字段都塞进 patch：

  patch: {
    形态: args['形态'],        // undefined
    项目: args['项目'],        // undefined
    智能体: args['智能体'],    // undefined
    自由标签: args['自由标签'], // undefined
    稳定性: args['稳定性'],    // "稳定"  <- 只有这个是真的
  }

Object.keys(patch).length === 5，宿主以为"五个字段都要改"，
撞上 形态=undefined 就报 FIELD_EMPTY。

工具的语义是「改某几个」，被按 UI 编辑器的「整组替换」实现了。

## 修法

只把模型**真正给出**的字段放进 patch：

  const patch = {}
  for (const field of [...6个字段]) {
    const v = args[field]
    if (v !== undefined && v !== null) patch[field] = v
  }
  if (Object.keys(patch).length === 0) return PATCH_EMPTY

关键：undefined 跳过，但**空数组/空串保留** ——
那是模型想显式清空，必须让宿主报错，不能静默吞掉。

## 三层语义（这次想清楚了）

  工具 dtm_retag   改某几个    -> patch 只含给出的字段
  UI 编辑器保存     整组替换    -> patch 含全部 6 个字段（草稿本就全有）
  模型想清空标签    显式清空    -> patch 含 自由标签:[]

三层不能混用。之前就是拿 UI 语义做了工具。

## 回归测试（新增 12 条）
