# dsh-tag-memory

DSH 插件：让智能体**有一份自己的记忆库**——存成 CSV，稳定读写，闲时还能整理。

每轮自动把一份**标签字典**交给模型，由它判断「这条该不该记、每个维度取什么值」；
写和查交给两个工具；条目在界面上看得见、搜得到、导得出；备份 / 恢复 / 合并都在那一页上。

## 解决什么问题

- **换个会话就失忆**：上一轮学到的东西，这一轮不在了。
- **记忆看不见**：谁记了什么、记到哪一步，没有一处能翻。
- **不敢让它自己记**：模型自由发挥写进去的东西格式五花八门，回头查不动也改不动。

**答案**：记忆只有一种形态——**一张只追加的 CSV**。模型只管判断，程序只管落笔。
于是它同时是一张随时能翻的表格、一份随时能导出的 CSV、一个随时能备份和回滚的文件。

## 是什么形式

一个插件，三块：

| 文件 | 挂在哪 | 干什么 |
|---|---|---|
| `preset.js` | 每个智能体 | `systemPrompt.section` 每轮注入**标签字典**；注册 `memory_write` / `memory_recall` 两个工具 |
| `index.js` | DSH 宿主 | **记忆文件托管**：探测各智能体的 `MEMORY.md`，写一段受控的说明块；挂 `/tag-memory-api` 给界面取数 |
| `client.js` | 浏览器 | **「记忆」页**：条目表格 + 维度筛选 + 搜索；标题行上带 **备份 / 恢复 / 合并** |

**零依赖**：不引入向量库、外部 API 或服务，全部落在本地文件上。

## 两段式：模型判断，程序执行

字典里写着每个维度能取什么值、有什么规则（`稳定性` 只有 `稳定` / `易变`；`深度` 只在
`类型=记忆` 时才有值……）。**模型读字典、填字段、调工具；编号、校验、追加、去重、筛选、返回，
全是程序干的。**

好处是**可回溯**：库里每条都带着当时「为什么记、凭什么这么判」。
判定规则以后改了，历史条目也不会被悄悄改写。

## 记忆库

一条 16 列的 CSV：

```
id 内容 时间 环境 原因 备注 稳定性 成熟度 距离 角色 项目 状态 关键词 工具 版本 依据
```

加一份维度字典（schema）。默认放在 `<DSH_HOME>/skills/marsma101-tag-memory`，
可用环境变量 `DSH_TAG_MEMORY_SKILL_DIR` 指到别处。

**只追加**：新记录追加到末尾，旧条目靠 `状态` 退场（`被取代` / `已归档`），**不删行**。
所以库只有一个方向长——任何一版都能原样备份、原样回滚。

## 「记忆」页

同一页组件挂三处（`sidebar.panellist` 的全局面板按钮 + `main` 的主区页面 +
`settings.section` 的设置栏）。数据全走宿主的只读接口。

| 槽 | 作用 | 位置 |
|---|---|---|
| `sidebar.panellist` | 侧边栏按钮（图标 + 「记忆」） | `order: 5`，紧排在官方**插件**按钮（`order: 0`）下面 |
| `main` | 侧边栏按钮切过去的主区页面 | `key: 'tag-memory'`；shell 的 `.centerCol` 是 `overflow:hidden` 且高度确定，**面板得自己当滚动容器**（`.tm-panel` = `height:100% + overflow:auto`），顶部再让出 `--dsh-frame-top-clearance` |
| `settings.section` | 设置里的**「记忆」**一栏（第二入口，同一组件） | `order: 60` |

浏览能力：

- **表格视图**（默认）：库就是 CSV，所以一行一条、一列一个字段。**列名与列序都照库自己的表头走**；
  默认只摆十列（`id 内容 时间 稳定性 成熟度 距离 角色 项目 状态 关键词`），环境/原因/备注/工具/版本/依据
  这些长文本或常空的留在「详情」里。表头与勾选列常驻，列多时横向滚动，长文本截断（悬浮看全文）。
  设置页窄，默认给**卡片视图**；右上角随时切换，选择记在 `localStorage`。
- **维度下拉**：每个维度一个下拉（选项带计数、已选打 ✓），横向排一行；选一个取值叠加一条条件，同一个再选一次即取消。
- **排序** `sort`：`time_desc`（默认）/ `time_asc` / `id_desc` / `id_asc`，按自然序比较（`M-20260101-002` 这类也排得对）。
- **分页** `limit` + `offset`，页尾「加载更多」；`hasMore` 指示是否还有。
- **含已归档**：默认排除 `被取代` / `已归档`；开关打开时把 `状态` 全集 + `留白` 显式写进条件。
- **详情展开**：每条可就地展开全部非空字段；正文超过 120 字先折叠。
- **多维选择**：同一维度可多选（维度内 = 或，维度间 = 与）；当前条件以**面包屑**显示，可逐个撤掉。
- **勾选带走**：勾选条目（含全选本页 / 清空）→「复制 Markdown」或「导出 CSV」；每条也有单独「复制」。
- **本地记忆**：条件 / 排序 / 每页数存 `localStorage`，重开设置页仍在。
- **键盘**：`/` 聚焦搜索框，`Esc` 清空全部条件与关键词。

条目本身**只读**：写入仍由智能体经 `memory_write` 完成。

### 版式：主位通则

**用户要看的、要点的放主位；说明、状态、设置退到次位并默认收起。** 判据一句话：
这东西用户「每次都要看」还是「出了事才看」？

| 位置 | 内容 |
|---|---|
| 标题行（右对齐） | **立即备份 / 恢复… / 合并… / 设置备份地址…** 四颗按钮——要点的，跟标题同一行，不另占一张卡 |
| 标题下面一行 | 备份现状：地址 · 上次时间 · 库条数与条数差 · 份数/占用 · 盘上余量 · 「该备份了」 |
| 正文（主位） | **记忆条目**：维度下拉一行 + 搜索/排序/每页/含已归档 + 勾选工具条 + 表格/卡片 |
| 页尾（默认收起） | **维护与状态**：记忆文件托管明细 + 手上的备份列表（都是「出事了才看」的） |

### 备份 / 恢复 / 合并

- **没有默认备份地址。** 地址存在 `store/backup.json` 的 `backupDir`，空就是没设。
  点「立即备份」而地址为空 → **直接展开「设置备份地址」面板**，不是弹一句提醒。
- **选一次就记住。** 点「设置备份地址」会弹 DSH 的**系统文件夹选择框**——就是开新会话选工作区时
  弹的同一个框（`ctx.uiWorkspace.pickDirectory()`，native / 内建浏览两种后端它自己适配）。
  **选中即落笔**：面板顶上那行「当前地址」立刻跟着变，**刷新 / 重开界面都还是它，直到你重选**。
  手填绝对路径的走右边「保存这个地址」。**存地址与立刻备份是两件事**——备份归标题行的「立即备份」。
- **地址只有一个落笔点**：`commitDir()` → `POST /backup/dir`。选文件夹、内建浏览的「就选这个目录」、
  手填后保存，全汇到它；没有第二条路能偷偷改地址。
- **两级兜底**：拿不到 `uiWorkspace`（或它没有原生选择能力）→ 退回**内建目录浏览**
  （面包屑 + 子目录 + 「就选这个目录」）；连这个也没有 → 输入框还在，手填绝对路径。
  ⚠️ **不自己 spawn 进程弹框**——试过 PowerShell 的 `FolderBrowserDialog`：框开在别的窗口后面，
  等于弹不出来（Windows 只把前台激活权给前台进程）。用 DSH 那道门就没这问题。
- **立即备份**：备 `memory.csv` / `index.md` / `backup.json` 三件套，文件名带戳 `YYYYMMDD-HHMMSS`；
  校验四项（字节数 / SHA-256 / 解析器数的记录数 / 无 BOM）全过才更新水位；
  戳上已有内容不同的同名文件就**往后挪一秒**——**备份从不覆盖已有内容**；超过 `keepCopies` 份轮转最旧的。
- **恢复 = 整体替换**（不是补缺失）：先验它能读并把内容读进内存 → **强制先留档当前这一版**
  （失败就中止，一个字节不动）→ 写回 `memory.csv` + `index.md`（`backup.json` 不还原，那是设置不是记忆）
  → 复核记录数，对不上就报错并指出用哪份回退。
- **合并**：给一份外来 `memory.csv` 的绝对路径 → **先预演**（一个字节不落），把
  「新增 / 重复跳过 / id 撞号改新号 / 加不进去的 / 内容一样但标签不一样」**逐条**交代清楚 →
  看过再「确认合并」。守的铁律是：**先留档、只追加、不重写、不删任何条目、id 撞号按内容判**。
  预演自己就做校验，不合规的行当场挑出来（连原因一起），不会等真合并才一条条失败。

## 记忆文件托管（`index.js` / `lib/notice.mjs`）

插件的字典注入接管之后，各智能体的 `MEMORY.md` 里就只剩一段说明。三条规矩：

1. **只认标记**：只动 `<!-- BEGIN dsh-tag-memory notice -->` 之间的内容，块外一个字节不碰；
   文件没有标记就当用户自己写的，**只追加、不重写**。
2. **只追加 / 原位替换**：有标记就替换块内，没有就追加到末尾；旧的手工字典块会被顺手接管替换掉。
3. **不能轻易丢**：首次落笔先留 `.bak-<时间戳>`；插件每次挂载（以及新智能体出现时）核对标记，不在就补回。

探测哪些文件算「记忆文件」由 `config.memoryFileNames` 决定，默认只认 **`MEMORY.md`**（大小写不敏感）。
目录不存在、文件不存在 → 跳过。

## 接口

| 端点 | 方法 | 返回 |
|---|---|---|
| `/tag-memory-api/overview` | GET | 是否就绪、库/字典路径、维度取值与计数、记忆文件托管状态 |
| `/tag-memory-api/entries` | GET | `?cond=<JSON>&q=<关键词>&sort=<排序>&limit=<n>&offset=<n>` → 命中的条目（含 `total` / `shown` / `hasMore`） |
| `/tag-memory-api/heal` | POST | 立即重跑一次记忆文件自愈，返回 summary + 新状态 |
| `/tag-memory-api/backup` | GET | 备份现状：地址是否已设、上次时间/条数、条数差、份数/占用/盘上余量、最近几份、到点没 |
| `/tag-memory-api/backup` | POST | `{label?}` → 立即备份。**没设地址时返回 `code:'NO_DIR'`**，界面据此切进「设置备份地址」状态 |
| `/tag-memory-api/backup/dir` | POST | `{dir}` → 设置备份地址（绝对路径；不存在就建；建不了/不可写就报错不落配置） |
| `/tag-memory-api/restore` | POST | `{stamp}` → **整体替换**成那一版；先强制留档当前版，换完复核记录数 |
| `/tag-memory-api/merge` | POST | `{path\|text, apply?}` → 合并外来 `memory.csv`；不传 `apply` 就是预演（不落笔） |
| `/tag-memory-api/picker` | GET | 这台 DSH 的目录选择后端是 `native`（弹系统框）还是 `browse`（列目录） |

## 自检

```bash
node scripts/selftest.mjs   # 127 项断言；全程沙箱（临时复制一份记忆库），不碰任何 live 数据
node scripts/install.mjs    # 只读校验：包结构 + profile 清单 + 预览会写哪些记忆文件
```

交付/测试用命令：`selftest.mjs` 全过 + `install.mjs`（check）全 PASS 即可视为可安装。

## 安装

```bash
node scripts/install.mjs                         # 只读校验 + 预览会写哪些记忆文件
node scripts/install.mjs --apply                 # 安装（链接 + profile 清单 + 写记忆块）
node scripts/install.mjs --apply --wire-presets  # 顺带把 /preset 行接进各智能体的 agent.cordis.yml
node scripts/install.mjs --dsh-home <路径> --profile <名>   # 装到别的 DSH / 别的 profile
```

装完需**重启 DSH** 才生效。所有被改的文件，脚本都会先留 `.bak-<时间戳>`。

> 客户端那半（`client.js`）DSH 会自己热更，改完刷新浏览器即可；
> **宿主那半（`index.js`）只在进程启动时装载**，改了必须重启。

## 配置

`index.js`（profile 行）：

```yaml
- id: tag-memory
  name: dsh-tag-memory
  config:
    memoryFileNames: ['MEMORY.md']   # 探测哪些文件算「记忆文件」
    notice: true                     # 关掉则不写记忆块
    migrateLegacyDict: true          # 是否接管旧的手工字典块
```

`preset.js`（每个智能体）：

```yaml
- id: tag-memory
  name: 'dsh-tag-memory/preset'
  config:
    dir: !!js "process.getBuiltinModule('node:url').fileURLToPath(new URL('.', baseUrl))"
```
